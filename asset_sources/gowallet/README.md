# Coin artwork provenance

These are the exact published PNG bytes from the coin repositories supplied by
the user. The assets are embedded in an SVG layout container for compatibility
with the inherited Flutter SVG icon renderer; they are not vector redraws.

- SCASH: https://github.com/ScashNetworkCommunity/scash/blob/HEAD/src/qt/res/icons/scash.png
- SHIC: https://github.com/shibacoinppc/shibacoin/blob/HEAD/src/qt/res/icons/shibacoin.png
- Retrieved: 2026-09-06.

Preserve each project's attribution/license. Application background and controls
retain GOwallet's approved palette. Coin artwork retains its own source colors.

The existing GOwallet SVG mark is reused for the header, loading screen, theme
preview and application icon. A new logo design has NOT been approved or
generated: the requested Recraft vector service rejected both attempts because
the connected account requires a Basic plan or higher.
