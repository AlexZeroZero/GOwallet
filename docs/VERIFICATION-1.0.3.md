# GOwallet 1.0.3：生物识别修复与 DINGO

日期：2026-09-08。版本 **1.0.3+12**，包名 `org.gowallet.pow`。

## 改动

- 生物识别成功即可通过，不再因系统提示框关闭与 Flutter 前台恢复的先后顺序而停在 PIN 页。
- PIN 仍是备用方式。取消、失败或无法使用生物识别时可使用 PIN；错误 PIN 限流保持不变。
- 冷启动、返回前台和敏感操作验证使用同样的保护。等待只允许短暂的 inactive 状态；
  真实后台、超时、页面销毁或新验证尝试都会使旧结果失效。
- 新增原生 Dingocoin（DINGO）：第三方 TLS Electrum、地址恢复、本地签名、币种图标、
  行情标识、交易浏览器。共用创世块的链额外核验第一块。
  详细参数与兼容边界见 [DINGO.md](DINGO.md)。
- 保持旧签名、密钥存储和数据库 schema。SQLite 构建新增可选本地源码缓存，仍强制校验同一 SHA-256。

## 限制

这是项目侧测试，不是独立机构审计。本次未重新运行 MobSF、ClamAV 或 VirusTotal，
没有启动此前关闭的 Docker。1.0.2 的 59/100 或查毒结果只适用于历史 APK，不能视为新版扫描。
本次没有验证实体手机的指纹硬件、TEE 安全性或所有 Android 厂商实现。

钱包仍不是完整 SPV 实现；TLS 与第一块检查不能保证节点诚实。节点可能隐藏历史、
谎报确认数或拒绝广播。助记词/私钥只在设备本地使用，用户应独立备份并核对币种与网络。
