  校验和错误、不支持的地址版本/长度被拒绝。

- 最终 APK 中三个 Isar 原生库与此前已加固、源码摘要完全相同的构建产物经 strip 后

## 验证边界

这是项目侧测试，不是独立机构安全审计。此次未重新运行 MobSF、ClamAV 或 VirusTotal，
没有启动 Docker，历史 APK 的扫描结果不能当作新版查毒结果。
未验证所有实体手机实现，也未执行真实资金交易。节点校验不是完整 SPV 共识验证；
第三方节点可能离线、遗漏记录或拒绝广播。

本次使用本地 JDK 17 运行项目 Gradle 构建，依赖锁文件保持不变。
SQLite 从既有缓存源码包构建并强制验证固定 SHA-256；Isar 复用摘要和字节均验证一致的
加固构建缓存。没有更改数据库 schema、已有币种派生路径或签名身份。
