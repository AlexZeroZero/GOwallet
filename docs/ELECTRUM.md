# Electrum 与非托管信任边界

GOwallet 1.0 使用兼容 Electrum JSON-RPC 的 TCP/TLS 接口。ElectrumX 是服务端实现之一；服务端必须支持对应币种，端口号本身不代表币种或加密方式。

| 币种 | 默认主节点 | 传输 |
| --- | --- | --- |
| SCASH | scash.gozero.trade:50002 | TLS，校验证书 |
| SHIC | shic.gozero.trade:50012 | TLS，校验证书 |
| PEP | electrum.pepeblocks.com:50002 | TLS，第三方 |
| PEP 备用 | electrum.pepe.tips:50002 | TLS，第三方 |

公共节点可变更或停机，这不是可用性承诺。可在钱包网络设置中新增兼容节点；节点运营者不需要用户助记词、私钥或手机 PIN。

## 数据和信任

GOwallet 为非托管式钱包客户端，不代管用户私钥或资产。所有连接的节点由相关币种项目官方或第三方节点运营者独立部署、运行和维护；被 APP 收录不构成项目官方认证。默认节点、备用节点和用户自定义节点均受各自运营方的可用性与服务条件约束。

因节点自身故障、停机、受到攻击、同步落后、返回错误数据或停止服务而产生的连接失败、余额/确认显示异常、查询或广播失败，属于节点服务侧问题，与 GOwallet APP 软件本身无关。APP 不保证节点的在线率、数据准确性或交易及时广播。节点离线本身不会改变链上资产归属；可切换兼容节点，核实链上状态后再决定后续操作。APP 自身逻辑或安全缺陷仍应通过本项目反馈渠道处理。

设备本地持有密钥并签名。节点收到 script hash 等查询，以及广播时的已签名交易；可以看到客户端 IP、时序、查询关联和公开交易。非托管不等于匿名。行情换算可请求其他数据服务，节点运营者也可能保留自己的访问记录。

TCP 是明文：网络中间人可能窃听或篡改响应。TLS 使用主机名和有效证书保护连接，不应关闭证书验证。普通 Cloudflare 免费 HTTP CDN 不直接代理任意 Electrum TCP/TLS 端口；DDoS 中转、WireGuard 与节点隔离属于部署层，不能由客户端保证。

应用在签名前验证输入原始交易的规范序列化、txid、输出索引、金额及归属脚本，拒绝重复或不一致输入。它也限制节点推荐费率，核对广播响应中的 txid。但是没有完整的区块头 PoW、Merkle 与链选择验证；创世块检查只能检查网络标识，不能证明服务器诚实。节点可遗漏数据、提供过期 UTXO、谎报确认、拒绝转发；返回正确 txid 也不能证明广播或确认成功。广播状态未知时先刷新检查，避免盲目重复付款。

## 自定义币种与自定义网络

币种参数需匹配地址版本、Bech32 前缀、精度、派生路径、网络标识及 Bitcoin 兼容交易/签名规则。同样叫 Electrum 并不意味着交易格式相同。额外字段、不同 sighash、隐私协议、特殊成熟期或超过当前解析器 1 MB 限制的交易可能不兼容。先使用无资金或小额测试，不能把参数导入当成完整适配审计。

更换同一币种节点只是改变查询/广播服务，不会迁移链上资产。修改派生路径或币种配置可能使旧地址不可见，务必先备份并核对参数。
