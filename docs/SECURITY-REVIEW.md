# GOwallet 1.0 安全审核说明

> 版本提示：本文保留 1.0.0 的历史检查结果。后续修复、新 APK 校验值和未解决项见 [1.0.1 安全修复与验证](VERIFICATION-1.0.1.md)。

本记录汇总 2026-09-06 的源码检查及 1.0 发布验证。性质为开发过程中的代码复核、攻击模拟、回归与发布包检查，**不是独立第三方渗透测试或安全认证**。未进行真实资金攻击或交易广播。

## 已修复且包含在 1.0 中的问题

| 问题 | 风险 | 修复与证据 |
| --- | --- | --- |
| 传统地址输入金额直接信任节点，实际手续费可远高于显示值 | 高 | 签名前取得原始前序交易，验证规范编码、txid、vout、金额、本地公钥对应脚本，拒绝重复输入。`verified_prevouts.dart`、交易安全测试 |
| 节点费用响应缺少数值、长度、指数和费率上限约束 | 中 | 有界数值解析，应用各币种推荐费率上限，只回退到已验证缓存。`bounded_fee.dart`、交易安全测试 |
| 直接使用广播响应作为本地交易 ID | 中 | 数据库写入前核对本地算出的 txid；不一致返回广播状态未知。交易安全测试覆盖生产发送入口 |
| 新备份允许过短口令 | 中 | 新建手动/自动备份要求去除首尾空白后至少 12 个 Unicode 字符；旧备份解密兼容。备份测试 |

输入金额攻击的无资金合成样例：实际输入 1,000,000,000 最小单位，节点声称 100,000,000，输出 99,999,000；旧路径显示费用 1,000，实际签名费用为 900,001,000。测试验证旧交易签名成立，并验证当前生产签名入口拒绝伪造金额。该交易未广播。

额外检查包括：二进制长度分配边界；原始交易缓存上限 128 笔/4 MiB；备份 PBKDF2-SHA512（v2 每阶段 210,000 次）和 XChaCha20-Poly1305 认证加密的错误口令/篡改拒绝；PIN 限速；后台认证失效；截图开关；Android 禁止系统备份；TLS 证书验证。长度合规并不能让弱口令自动变强。

## 公开验证证据

当前发布的精确 APK 哈希、签名、测试计数、依赖公告结果与恶意软件扫描状态见 [VERIFICATION.md](VERIFICATION.md) 及 `evidence/`。测试源文件包含在 `test/gowallet*_test.dart`、`test/scash_shic_signing_test.dart` 和 `test/scash_shic_wallet_test.dart`，可自行运行。

依赖公告查询只覆盖 `pubspec.lock` 中的 Pub 托管包，不覆盖 Git/path 依赖、原生库、Flutter/Android SDK，也不能发现尚未收录的漏洞。源码密钥扫描不能证明不存在所有敏感数据。查毒扫描与代码安全审核是不同的检查。

## 尚未解决的信任边界与未覆盖项目

2026-09-07 补充的 [MobSF 自动静态扫描](AUTOMATED-SECURITY.md) 评分为 59/100，包含 CBC 代码和原生库加固等未关闭告警。该报告公开了完整工具输出、初步核查意见与覆盖限制，不能将本文件中“已修复”的旧问题理解为整个 APP 已无安全问题。此次没有独立人工审计或动态设备扫描。

### 非托管与节点服务声明

GOwallet 是非托管式钱包。助记词和私钥由用户在设备本地保管，开发者不托管资产，也无法恢复丢失的助记词。所连接节点由相关币种官方或第三方节点运营者独立部署和维护，是否为官方节点应以币种项目公布的信息为准。

因节点自身故障、停机、攻击、同步延迟、错误响应或停止服务导致的连接、查询、余额显示或广播问题，属于节点服务侧问题，与 GOwallet APP 软件本身无关。APP 不对节点在线率、返回数据或广播及时性作保证。可切换兼容节点核实链上状态；APP 自身缺陷应作为 APP 问题反馈。本声明不改变下列技术限制和审核范围。

- 没有完整 SPV、PoW、Merkle 和链选择验证；节点仍能谎报余额/确认、隐藏交易、拒绝广播。原始前序交易核验不证明确认或未花费。
- TLS 不保证节点诚实；TCP 是明文；节点可观察访问 IP 与查询关联。
- root/恶意系统、注入、无障碍滥用、已解锁手机及允许截图均可能暴露信息。
- 自定义币种必须适配其地址、派生和交易签名格式；不保证所有 Electrum 小币兼容。
- 未进行独立全量密码学审计、完整 Git/native 依赖审计、实机硬件攻击、真实资金全链路广播及“导出→卸载→恢复”整机演练。
- 既有大文件仍可能包含上游静态分析提示；不能将针对性分析通过表述为整个项目零告警。
- APP 检查不证明节点的抗 DDoS 能力、在线率或运营方隐私政策。

发现风险请参阅 [私密漏洞反馈](../SECURITY.md)。源码开放与检测结果帮助复核，不构成资产安全保证。
